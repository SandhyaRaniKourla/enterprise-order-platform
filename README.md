# enterprise-order-platform
Production-ready event-driven Order Management using .NET
Project name: enterprise-order-platform

Business scenario

A retailer receives orders through a web application. An order must pass through several business processes:
1. Customer places an order.
2. System validates customer and order details.
3. Inventory is checked and reserved.
4. Payment is processed (simulated initially).
5. Order is confirmed.
6. Shipping is initiated.
7. Customer receives notifications.
8. Customer can track the order.
